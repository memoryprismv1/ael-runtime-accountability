# Security and data handling

This is a local prototype. Do not use it to store sensitive or regulated data without independently assessing security, access controls, encryption, backups, and deletion behavior.

- Never commit personal databases, chat exports, generated handoffs, credentials, or private account/project memory.
- The optional Ollama bridge is intended for loopback-only local service use; do not broaden its host policy without security tests and an explicit design review.
- Report reproducible security issues privately to the repository maintainer rather than publishing exploit details in an issue.
- Passing unit tests is not a security audit or a production-readiness guarantee.
