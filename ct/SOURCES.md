# Authoritative AEL Sources

**Authorship boundary:** AEL and its underlying framework are the work of the Memory Prism author. This repository is an implementation prototype; it does not claim to originate or redefine AEL.

The following pages are linked in the author's specified reading order. The pages, not this implementation, control the framework's meaning.

1. [Vive et Vivere Sinas](https://www.memoryprism.com/essays/signal-and-cost/vive-et-vivere-sinas) — foundational frame.
2. [AEL and AI](https://www.memoryprism.com/positions/ael-and-ai) — application to AI systems.
3. [The Intern Who Never Sleeps](https://www.memoryprism.com/positions/ai-intern-monkeys) — generation/verification cost asymmetry.
4. [AEL Runtime Accountability — V1](https://www.memoryprism.com/readings/ael-runtime-accountability) — runtime mechanisms.
5. [Learning the World Through Others](https://www.memoryprism.com/essays/signal-and-cost/learning-the-world-through-others) — learning from outcomes and environmental traces.

Supporting design notes and the V1 evidence pack informed development but are not reproduced in this public prototype package. External research listed within the author's documents should be consulted at its original source and is not the origin of AEL.

Mechanism status and implementation limits are recorded in [`DESIGN_ALIGNMENT.md`](DESIGN_ALIGNMENT.md). Implementation claims should not be read as a replacement specification.
